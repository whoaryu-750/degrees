# CS50 AI - Degrees

This submission contains the completed `shortest_path` function for the CS50 AI Degrees project.

## Algorithm

The solution uses Breadth-First Search (BFS) with `QueueFrontier` to find the shortest path between two actors.

## Submission

Place `degrees.py` in the CS50 AI Degrees distribution-code directory before running the project.

Example:

```bash
python degrees.py small
```

Do not include the `small` or `large` datasets when submitting to CS50.
